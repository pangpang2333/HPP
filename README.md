# 聚典核校用户反馈大屏（Supabase 云端版）

打开页面需要先登录；登录后会从 Supabase 拉取最新数据，在管理页保存/删除后会自动同步到云端。本地 IndexedDB 仍作缓存，断网后可继续查看已缓存内容。

**账号**：使用你自己的邮箱（创建时绑定的那个）登录。仓库可以公开，但数据与管理操作都需要登录后的会话。

## 本地预览

用任意静态服务器打开本目录，例如：

```bash
npx serve .
# 或 python3 -m http.server 8080
```

然后访问提示的地址。不要直接用 `file://` 打开（浏览器会限制部分能力）。

## 部署到 GitHub Pages

把本目录里的文件推到你的 Pages 仓库（例如原来的 `pangpang2333.github.io/HPP/`）：

1. 用本目录内容覆盖仓库里对应静态文件（至少包含 `index.html`、`app.js`、`styles.css`、`logo.svg`、`config.js`）。
2. 提交并推送后，打开：https://pangpang2333.github.io/HPP/
3. 首次打开会先出现登录页；登录成功后自动从云端加载反馈。

## 安全说明

- 页面带登录门禁：未登录看不到管理与大屏数据读写。
- Supabase RLS 已限制为仅 `authenticated` 角色可访问表数据；anon 无法直接读写。
- `config.js` 里的 anon key 仍会暴露在前端（Supabase 常规用法），真正的保护依赖登录会话 + RLS。
- 不要对外公开你的登录密码；需要多人使用时再单独建账号并收紧策略。

## 数据备份

「展示设置」里仍可导出/导入 JSON。覆盖导入会先清空云端再写入；合并导入会把文件里的行 upsert 到云端。
